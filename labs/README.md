# 실습 기록

허가된 교육용 실습이나 직접 만든 환경에서 확인한 내용을 기록하는 곳입니다. 실습 하나당 Markdown 파일 하나를 만듭니다. 예: `portswigger-user-id-controlled-by-request-parameter.md`.

새 글에는 다음을 적습니다.

1. **출처와 범위:** 실습 링크, 날짜, 테스트가 허용된 환경
2. **목표와 예상:** 무엇이 일어나야 정상인지, 어떤 취약점을 확인할지
3. **과정:** 사용한 계정과 요청의 핵심 부분, 바꾼 값
4. **관찰:** 서버 응답과 실제 화면에서 확인한 결과
5. **이해:** 왜 이런 결과가 나왔는지, 어떻게 막을 수 있는지
6. **남은 질문:** 실패한 시도와 다음에 확인할 점

공개 전에 쿠키, 토큰, 비밀번호, 개인정보를 지우거나 가립니다.
