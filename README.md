# 웹 모의해킹 학습 기록

웹 취약점을 공부하며 **개념 이해 → 허가된 환경에서 실습 → 원인과 대응 정리** 순서로 남기는 저장소입니다. 현재는 입문 단계이며, 직접 확인한 내용과 아직 이해하지 못한 내용을 구분해 기록합니다.

## 기록 목록

| 폴더 | 내용 |
| --- | --- |
| [concepts](concepts/) | 실습 중 몰랐던 HTTP, 인증, 인가 등의 개념 |
| [vulnerabilities](vulnerabilities/) | 취약점의 발생 조건, 영향, 원인, 대응 방법 |
| [labs](labs/) | 허가된 실습에서 세운 가설, 시도, 관찰 결과 |

## 기록 방식

1. 실습 중 모르는 용어가 나오면 `concepts/`에 내 말로 설명합니다.
2. 취약점을 이해하면 `vulnerabilities/`에 정상 동작과 취약한 동작의 차이를 적습니다.
3. 직접 실습한 경우 `labs/`에 출처와 실험 과정을 기록하고 관련 글을 서로 연결합니다.

실습은 교육용 실습 환경 또는 명시적으로 허가받은 대상에서만 진행합니다. 공개 글에는 실제 계정의 비밀번호, 세션 쿠키, 토큰, 개인정보를 포함하지 않습니다.
