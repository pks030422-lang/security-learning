# 웹 모의해킹 학습 기록

웹 취약점을 하나씩 공부하며 알게 된 개념, 공개 리포트 분석, 허가된 실습 결과를 **취약점별 글 한 편**에 모읍니다. 현재는 입문 단계입니다.

## 취약점별 기록

| 주제 | 진행 상태 |
| --- | --- |
| [IDOR](vulnerabilities/idor.md) | PortSwigger 입문 실습 1개 완료 · GUID·비밀번호 노출 실습 과정 기록 |
| [요청 본문을 통한 권한 상승](vulnerabilities/role-escalation.md) | `roleid` 실습 완료(본인 확인) · HTTP 요청 수정과 후속 CTF 기록 |

## 기록 원칙

- 개념마다 파일을 만들지 않고, 그 개념이 필요했던 취약점 글에 먼저 적습니다.
- 공개 리포트에서 읽은 내용과 직접 실습해 확인한 결과를 구분합니다.
- 실습은 교육용 환경이나 명시적으로 허가받은 대상에서만 진행합니다.
- 공개 글에는 실제 비밀번호, 세션 쿠키, 토큰, 개인정보를 올리지 않습니다.

여러 취약점에서 반복해서 쓰이는 기초 개념이 쌓이면 그때 공통 문서로 분리합니다.
